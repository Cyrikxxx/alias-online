# Уровни сложности — большие наборы

Три набора, которые живут отдельно от тематических категорий. Они специально пересекаются с темами: игрок, выбравший «Обычный уровень», не должен упереться в потолок.

Расчёт: партия ≈ 150 слов. При ~1300 словах в наборе это восемь-девять партий подряд без единого повтора.

Слова внутри набора уникальны, и наборы не пересекаются между собой — слово живёт ровно на одном уровне. Блоки нужны только для чтения и правки; в игре это один общий пул.
